功能一的后续链路

告警 → 相机 / 目标匹配 → 单次约 20 秒标注录像 → 文件检查及访问。前端决定告警持续显示多久。本模块当前解析和留档消息，尚无自己生成的 JPG / MP4 产物。

功能二的后续链路

持续 AIS 状态 → 按位置和时间关联雷达目标 → 登记尺度交叉校验 → 可信高度。本模块提供 AIS 输入，未实现点云测高和最终融合算法。
