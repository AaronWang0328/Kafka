两条业务线，共用一套可靠接入流程

连续 AIS 持续提供船舶身份、位置和尺度；告警是独立事件，触发媒体留存。AIS 的发布与接收不需要等待告警。

功能二：持续 AIS → 雷达测高融合

AIS 状态与质量信息 → 下游按位置和时间关联雷达目标 → 用登记尺度交叉校验 → 输出可信高度。

本项目当前提供 AIS 输入与接入证据。点云跟踪、测高和融合算法尚未在本模块实现。

功能一：告警 → 图像 / 视频留存

告警与媒体指令 → 下游匹配相机和目标 → 单次触发约 20 秒标注录像 → 产物落盘、记录与访问。

本项目当前解析并归档消息。是否持续显示告警由前端决定；本模块不生成录像。
